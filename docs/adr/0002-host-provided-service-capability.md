# 安装式服务插件使用宿主提供的受限后台能力

为使应用中心安装插件后能够持续向外部客户端提供服务，同时保留现有页面应用的安全边界，用户于 2026-11-02 确认：底层飞牛影视协议由主程序提供，插件控制安装、授权和启停；不增加可执行任意插件后台脚本的运行时。

未安装或未启用对应服务插件时，不提供飞牛影视兼容能力；安装后也需先配置影视连接账号、授权目录并主动启动服务，不能仅凭安装自动暴露网盘。关闭管理页面不停止已启动的后台服务，停用或卸载则拒绝新请求、撤销会话并中止相关进行中的传输；已传到客户端的字节无法撤回。原 `/fntv` 地址要求已由 [ADR-0004](0004-root-address-without-fntv-prefix.md) 取消。

这是受限宿主能力而非通用服务端代码插件。其代价是部分协议修正或升级需要同时更新主程序，不能承诺所有后台功能都能仅靠更新插件包完成。具体包声明格式与宿主接口属于后续实现设计，不由本决策指定。
