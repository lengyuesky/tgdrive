# 散放视频先整理到番号目录，再刮削

用户于 2026-11-14 确认：散放视频指尚未位于对应番号目录的网盘视频。手动处理时先从文件名、必要时父目录名确定番号，再将视频移入对应番号目录并保留原文件名，之后执行影视刮削；已经位于对应番号目录的视频就地刮削，番号不能唯一确定时先等待用户输入或选择。

这一顺序满足用户按番号组织影片的要求，并使后续 NFO 和海报位于整理后的目录。代价是网盘位置的变化先于后端刮削结果，不能将刮削失败等同于文件从未移动。

第四轮用户进一步确认：番号目录建在视频原父目录下，已有同番号目录直接复用；明确关联的字幕、同名 NFO 和海报随视频移动，共享文件由用户选择。遇到同名冲突跳过该视频的整理，移动成功而刮削失败则保留新位置供手动重试；取消或关页停止后续操作，保留已完成结果，并核对正在执行请求的最终状态。

第七轮确认：预览之后源视频、配套文件、目标位置或拟覆盖资料发生名称、位置、内容或存在性变化时，执行与提交都必须阻止旧预览继续操作，要求重新预览。内容版本不能替代位置和资料集合核对；中断结果不明时保留待核实记录，核实后再由用户手动继续。30 天操作记录用于展示与核实，备份或旧应用版本恢复得到的未完成记录不直接续执行，需重新扫描确认当前网盘状态。
