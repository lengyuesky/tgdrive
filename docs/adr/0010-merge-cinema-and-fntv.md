# 影视页面与飞牛影视兼容服务合并为一款应用

[ADR-0003](0003-isolate-fntv-application-data.md) 为避免改动影视页面应用已有的数据格式，让飞牛插件独立保存媒体库、收藏和观看进度。用户于 2026-11-19 决定全部重写且不保留应用数据，这条理由不再成立，因此把两者合并为一款影视应用：一个应用后端管理影视媒体库、索引、收藏和观看进度，同时提供应用中心内的页面和供飞牛影视客户端连接的兼容服务。

不合并则媒体库组织、影视描述文件读取、视频封面选择和观看进度都要实现两遍，网页与飞牛客户端之间的进度也不互通。影视刮削保持为独立应用，因为它是唯一需要读写授权和访问外部资料来源的应用，不刮削的用户不必授予这些；刮削产物仍按 [ADR-0007](0007-scraper-sidecars-for-cinema-and-fntv.md) 以网盘文件交付。
