# 飞牛影视兼容服务通过应用中心安装并使用专用地址

用户于 2026-11-02 确认：飞牛影视兼容能力必须作为插件从 TGDrive 应用中心安装，供未修改的官方客户端直接连接，使用 `/fntv` 专用地址，不要求真实 fnOS 服务器中转。这不是主程序默认开放的一组服务接口，也不是仅增加一个配置快捷入口；应用安装是获得该能力的前提。

现有页面应用不具备服务端执行能力，因此安装式交付需要新的宿主支持。此决策只固定交付和接入边界；后台运行模型另由 [ADR-0002](0002-host-provided-service-capability.md) 确定，不授权任意插件执行服务端代码。

官方客户端是否接受并保留 `/fntv` 地址前缀仍待验证；该接入目标尚未被证明可行，不能以根路径、独立端口或依赖真实 fnOS 的代理方案悄然替代。已确认的启停、访问和数据边界及其余待决问题见 [设计记录](../fntv-compatibility.md)。

后续实测发现指定 Mac 客户端的握手请求不保留该前缀，用户随后明确取消 `/fntv`。接入地址改由 [ADR-0004](0004-root-address-without-fntv-prefix.md) 确定；本记录保留原决策经过，应用中心安装与独立兼容服务的交付要求不变。
