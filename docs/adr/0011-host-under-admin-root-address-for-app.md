# 宿主地址收进 `/admin`，根地址归用户指定的一个应用

飞牛影视客户端只向服务根路径发请求（见 [ADR-0004](0004-root-address-without-fntv-prefix.md)），而用户要求整个 TGDrive 只对外提供一个端口。用户于 2026-11-19 确认：宿主的全部地址（管理界面、接口、WebDAV、分享链接、健康检查）收进 `/admin`，`/admin` 之外的请求交给用户在应用中心指定的那一个应用；未指定时跳转到 `/admin`。宿主不写死任何应用，其他应用的对外入口使用 `/admin` 下按应用分配的固定前缀。

## Considered Options

- 为对外服务另开独立端口：不与宿主路径冲突，但用户要求只开一个端口。
- 让应用认领宿主根路径下的若干路径：宿主必须知道具体应用的路径，重新形成耦合。

## Consequences

- 旧地址不留别名：已发出的分享链接失效，WebDAV 客户端和原生客户端须改用新地址。
- 根地址与宿主管理界面同源，因此应用对外入口的全部响应由宿主强制加上禁止在本站执行脚本的响应头；应用的界面只在应用中心的沙箱页面内打开。
- 同一时间只能有一个应用使用根地址。
