# 客户端使用根地址，不再使用自定义 `/fntv` 前缀

指定 Mac 飞牛播放器在三种 `/fntv` 输入形式下，均向根路径发送 `/trimcon` 和 `/v/api/v1/sys/version`，原前缀要求未通过隔离验证。用户随后明确表示“不使用 /fntv”，因此取消客户端基路径和 `/fntv` 管理入口要求，改用服务的根地址以及客户端要求的协议路径继续验证；管理仍在应用中心安装的插件内完成。

此决策取代 ADR-0001 中的专用前缀要求，不改变应用中心安装、显式授权和启动、受限宿主后台、原文件直传、独立业务数据或无需真实 fnOS 中转等已确认边界。验证先用独立本地端口，避免触碰日常 TGDrive 服务；生产监听方式尚未部署，取消前缀也不等于允许默认开放服务。

根地址兼容仍需官方客户端真实握手、登录和合成视频播放证明。此前的前缀失败结果只是历史证据，不是新接入方案已通过的证明。
