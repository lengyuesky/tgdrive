# 宿主阅读索引与全库分页

## 设计

新增迁移 `0019_reading_index.sql`，用 SQLite 持久化表达式索引按文件名后缀分类（TXT、EPUB、PDF、CBZ、ZIP 和图片）。SQLite 随节点写入同步维护索引，不需要浏览器分批扫描，也没有关闭页面就丢失的后台扫描任务。漫画图片目录通过直属非隐藏图片节点发现。

`reading_tree_revision` 保存不可预测的修订令牌。节点增删、改名、移动、内容或可见性变化在同一事务内换新修订，事务回滚不发布修订；重启保持修订。与旧目录 `content_version` 不同，它能检测子文件变动。使用全局修订是保守取舍：无关目录发生变更也可能要求重新分页，不向插件暴露全盘文件或变更计数。

新增只读 RPC `library.page`（API v2，需 `files.read`），宿主页面在握手能力列表声明。App SDK 支持可选接口，旧宿主不显示“全库”入口。

## 接口

```json
{
  "roots": [12, 34],
  "kind": "all",
  "q": "示例",
  "format": null,
  "sort": "title",
  "limit": 40,
  "cursor": null
}
```

- 来源为 1～16 个稳定目录 ID。每次请求重新核验节点可见性和当前 App 目录权限；不接受越界根目录，不能用旧游标越权。
- `kind` 支持 `all`、`books` 或 `comics`。`all` 统一列出 TXT/EPUB/PDF、CBZ/ZIP 和图片目录；`books` 限定 `txt/epub/pdf`，`comics` 限定 `cbz/zip/images`。省略 `format` 或设为 null 不限制格式，也可指定该 kind 内的单一格式。
- 搜索为文件名子串，ASCII 字母不区分大小写，不是作者、书籍正文或远程元数据搜索。
- 排序支持文件名（`title`）及文件创建时间倒序（`added`）。每页 1～200 项。
- 返回 `entries[{file,format,source_ids}]`、`revision`、`next_cursor`、`has_more`。
- keyset 游标绑定修订、来源及筛选（包括 kind）。切换 `all`/`books`/`comics` 必须从首页重新请求；绑定不符返回 400；文件树已变化返回 409 和 `reading_index_changed`，要求从首页刷新。
- 本页在只读事务快照内执行。结果构造最多驻留 `limit + 1` 条；重叠来源去重。SQL 仍需递归遍历选中目录并可能排序，不能承诺任意大库常数时间响应，需结合性能指标压测。

## App 行为

阅读馆 `reader`（最低宿主 0.3.3）书库的“全库”视图通过 `kind=all` 读取全部已添加来源或单一来源的子目录，文本、归档与图片目录共用分页，不受旧的 2000 项已整理索引上限限制。当前页 40 项，前页游标最多保存 100 个，不保留已看页面的所有文件。

浏览位置存入 App 私有存储的 `library:host-position:v1`，CAS 串行保存，只占一条记录；重开时恢复页号、查询与当前页游标，必须重新通过宿主修订及权限检查。跨会话不保存整条前页链，需要向前返回时可从首页重新开始。读位置失败不覆盖旧位置，保存冲突不影响当前阅读。

原“作品/文件”视图保留作者元数据、分组和阅读状态筛选，仍明确受已整理范围限制。新“全库”视图不把未读取的进度标成“未读”，也不声称已有全库作者/分组/阅读状态索引。文件或权限变更事件会清除旧卡片并提示刷新；实际开读仍走原有稳定引用校验。

## 验证范围

后端合成 2005 个文件验证完整分页、无重复、无正文读取；覆盖子目录、重叠来源、改名后格式变化、回收站/恢复、越界根目录、非法筛选、旧游标失效。数据库测试验证修订事务性、重开保持及格式索引被查询计划使用。

App 单元测试覆盖当前页有界展示、位置保存/恢复、CAS 冲突、失败不覆盖、迟到请求、权限事件、重复/越界结果以及文本注入。新增桌面和手机模拟视口的真实沙箱流程验证 85 个合成文件三页、恢复、修订失效、搜索及开读。

本阶段是阅读文件索引，不是全库作品元数据索引；实体手机、十万级文件负载与长期内存压测尚需后续验收。
